# Проверка вёрстки

Сайт статический, поэтому достаточно открыть `index.html` и снять скриншоты страниц на трёх ширинах: 1440 (компьютер), 900 (планшет), 390 (телефон).

## Что снимать

Каждую страницу по адресу с хэшем: `#home`, `#catalog`, `#product/1`, `#contacts`, `#cart`, `#privacy`. Корзину и форму заказа смотреть с товарами: подставить `klin_cart` в `localStorage` (формат `[{"id":2,"selectedSize":"M","qty":1}]`) и открыть форму через `openCheckoutModal()`.

## Как снимать

Если доступен Playwright MCP, используй его: он умеет менять размер окна, наводить мышь и кликать.

Без него используй скрипт `scripts/shot.sh`:

```bash
bash .claude/skills/site-check/scripts/shot.sh <имя> <ширина> <высота> <хэш> <папка-для-скриншотов>
# пример: bash .claude/skills/site-check/scripts/shot.sh catalog-m 390 4000 catalog "$TMP/shots"
```

Скрипт запускает headless Edge. Ширину меньше ~500px Edge не даёт, поэтому для телефона скрипт сам оборачивает страницу в `<iframe>` нужной ширины. Скриншоты клади во временную папку, не в проект.

Длинную страницу режь на куски по ~1400px высотой, иначе картинка читается мелко.

## На что смотреть

1. **Двойные линии.** Граница блока плюс граница соседа складываются в жирную полосу: под шапкой страницы и списком, между последним товаром и итогом корзины, между нижним рядом карточек и футером.
2. **Горизонтальный скролл** на телефоне и обрезанный текст.
3. **Меню в шапке** на 390 и 360px: все пункты в одну строку, логотип по центру.
4. **Карточки каталога**: ровные ряды, второе фото подставляется только у товаров, у которых оно есть.
5. **Выравнивание по левому краю** контейнера: заголовки, метрики, фильтры, списки.
6. **Мелочи**: переносы слов по одному в подзаголовках, стрелки в кнопках, обрезка названий в две строки.
