# Запуск сайта

Сайт статический, сборки нет.

## Быстро

Открыть [index.html](../../../index.html) двойным кликом. Для просмотра этого достаточно.

## С локальным сервером

Нужен, если проверяешь запросы к Worker'у: с `file://` браузер может блокировать их из-за CORS.

```bash
cd D:/Project/klin-select
python -m http.server 8000
```

Адрес: http://localhost:8000 (страницы: `#catalog`, `#product/1`, `#cart`).

Сервер запускай в фоне, чтобы не блокировать терминал, и остановай, когда закончил.

## Внимание

Форма заказа отправляет настоящий запрос на `WORKER_URL` из `js/app.js`, и менеджер получит настоящее сообщение в Telegram. **Не отправляй заказ при проверке**, если пользователь прямо не попросил. Для проверки достаточно открыть форму (`openCheckoutModal()`) и проверить валидацию, не нажимая «Отправить».

## Остановка

Процесс на порту 8000: `netstat -ano | findstr :8000`, затем `taskkill /PID <pid> /F`.
